# 杭州宠伴 V1.0 — 可交互 HTML 原型

## 打开方式

直接在浏览器中打开 `index.html`。手机浏览器也可打开同一文件。所有演示信息存在当前浏览器的 `localStorage` 中。建议通过本地静态服务访问：`python3 -m http.server 8000`，然后访问 `http://localhost:8000`。

## 操作路径

1. 首页进入宠物详情，先完成三节演示课程和十道测评（至少八题正确），再提交四步领养表单。
2. 从顶部「PC管理后台」进入管理员端；在「领养申请初审」通过初审并模拟送养人同意；在「家访任务管理」录入志愿者、理由和截图，审核通过。
3. 返回小程序「我的申请」，签署演示协议、设置模拟押金和上传交接凭证，开始七天冷静期。
4. 「我的送养」提交六步送养资料，后台帖子审核通过后，帖子展示在首页。
5. 个人中心可提交投诉、查看测评记录、切换演示实名核验状态。后台可模拟黑名单限制、查看日志和工单。

## 重要边界

- 这是 HTML/CSS/JavaScript 的交互原型，**不是微信原生小程序源代码，也未部署到 Sites**。
- 宠物图片均为公开占位图，不是真实待领养动物。文件上传只记录文件名，没有上传服务器。
- 实名人脸、短信、视频、电子签章、微信支付/押金托管、资金退款、消息订阅、文件永久存储均为模拟或尚未接入。
- 视频学习完成勾选不具备防作弊属性；协议按钮不是合规电子签名。
- 七天冷静期按真实时间计算，不提供绕过。押金上限 300 元仅为原型占位设定，正式金额和业务合法性需要另行评估。
- 正式开发必须有后端状态机执行身份权限和状态变更，不能信任前端 localStorage。
- 送养人审核在 PC 演示端代操作，正式产品应改为送养人本人的受控权限。
- 管理端回访的志愿者判定、押金退回核验、上传实拍图片真实性检测、以及实名核验还需要真实实现。
